# Համակարգված մոդել և ութ տեսարան

Բեռնեք և զննարկիչով բացեք [անցանց դիտիչը](Viewer.html)։ Շրջեք, փոխեք հորիզոնական կտրվածքի բարձրությունը, ընտրեք ինժեներական շերտ կամ տարր։ Արտաքին ծառայության կարիք չկա։ Աշխատանքը ստուգվել է Chrome WebGL-ով՝ ջրահեռացման շերտի միացումով և D01 տարրի ընտրությամբ։

[Մետրային IFC4 մոդելը](apartment.ifc) պարունակում է դասակարգված պատեր, սյուն, դռներ, բացվածքներ, պատուհաններ, տարածքներ, վիտրաժներ, կահույք և ինժեներական համակարգեր։ IfcOpenShell-ով բացվել է 236 երկրաչափական տարր, 17 համակարգ, սխեմայի ստուգման ժամանակ գրանցվել է 0 սխալ։ Մարմիններն արտահանված են եռանկյունային երկրաչափությամբ։ Չափերը փոփոխելու բնօրինակներն են [սենյակներն ու պատերը](../02-design/design.json), [համակարգերը](../04-services/services.json) և [մոդելի երկրաչափությունը](scene.py)։ Դրանցից նորից գործարկեք `python 05-model/build.py`, ապա `python tools/build_viewer.py`։ Python միջավայրում մոդելի հավաքման համար պահանջվում է NumPy։

Ութ տեսարանն ու IFC-ն սնվում են նույն գագաթներից։ [Դիտակետերի մատյանում](../07-views/cameras.json) նշված են տեսախցիկի դիրքը, թիրախն ու հորիզոնական դիտանկյունը։ [Պատկերների ալբոմում](../07-views/Views.pdf) ամեն թերթի կողքին տեսախցիկի հատակագիծն է։ Ընտրված նյութերը, գույները և լույսի պայմանները նախագծային են։ Իրական ճակատը և շրջապատը լուսանկարներով չեն չափագրվել։

Վերարտադրելու համար մոդելի հավաքումից հետո Windows-ում `csc /optimize+ /r:System.Drawing.dll /out:Render.exe 05-model\Render.cs` հրամանով կազմարկեք ռենդերիչը, ապա գործարկեք `Render.exe ..\tmp\model 07-views 1152 6` այս պահոցի արմատից։ Առաջին թվով սահմանվում է լայնությունը պիքսելներով, երկրորդով՝ մեկ պիքսելի նմուշների քանակը։ PDF թերթերի համար գործարկեք `python tools/views.py`։ Տպագրական գործիքներն օգտագործում են ReportLab, pypdf և Windows-ի Arial տառատեսակները։ Autodesk-ի միջավայր տեղափոխելու ընթացքերը ներկայացված են [ծրագրային համեմատության մեջ](../08-review/Ծրագրային%20ընթացքեր.md)։
