# Համակարգված մոդել և ութ տեսարան · R3

Բեռնեք և զննարկիչով բացեք [անցանց դիտիչը](Viewer.html)։ Մկնիկով քաշելով՝ շրջեք մոդելը, բացեք հատակագիծը կամ փոխեք հորիզոնական կտրվածքի բարձրությունը։ Շերտերի ցանկով միացրեք ջրահեռացումը, ապա տարրերի ցանկում ընտրեք D01՝ խոհանոցի ճյուղը տեսնելու համար։ Դիտիչն իր երկրաչափությունը պահում է HTML ֆայլում։ Chrome WebGL-ով ստուգվել են շերտի միացումը, տարրի ընտրությունը և առանց արտաքին հարցումների աշխատանքը։

[Մետրային IFC4 մոդելը](apartment.ifc) ներառում է 8 տարածք, 13 բացվածք և 17 ինժեներական համակարգ։ IfcOpenShell-ը կարդացել և եռանկյունացրել է երկրաչափություն ունեցող բոլոր 238 տարրերը։ IFC4 սխեմայի ստուգմամբ գրանցվել է 0 սխալ։ Վերին ձախ B1 սենյակն ունի պատշգամբին նայող լուսամուտ։ Ստորին ձախ B2 ներքին սենյակն արտաքին պատուհան չունի։ Այստեղ նշված են ներհոսքի վանդակը, կլիմայական բլոկը և չորս առաստաղային լուսատուները։

IFC ծրագրում սենքի հատկությունների `Qto_SpaceBaseQuantities` բաժինը ցույց է տալիս մաքուր մակերեսը։ Կրող պատի `LoadBearing` հատկությունը միացված է։ Յուրաքանչյուր ինժեներական գծի `Apartment_ServiceRoute` բաժնում նշված է մոդելային տրամագիծը, իսկ ինքնահոս կոյուղու ճյուղերի համար նաև հատակագծային երկարությունը, անկումը և խողովակի հատակի սկզբնական ու վերջնական նիշերը։

Ութ պատկերները, IFC-ն և դիտիչի WebGL տեսքը կազմվել են նույն եռանկյուններից։ Դիտիչի կոորդինատները կլորացված են մինչև միլիմետր։ Մոդելային տեսարանների լուսատուների տեղերը և լուսային հոսքերը վերցված են համակարգերի ցանկից։ Նյութերը, վերին պահարանների ճակատներն ու երկնքի լուսավորությունը նախագծային մեկնաբանություն են։ Իրական ճակատը և շրջապատը լուսանկարներով չեն չափագրվել։ [Դիտակետերի մատյանում](../07-views/cameras.json) գրանցված են տեսախցիկի դիրքը, թիրախն ու հորիզոնական դիտանկյունը։ [Ութ թերթանոց ալբոմում](../07-views/Views.pdf) յուրաքանչյուր պատկերին կից կա տեսախցիկի տեղադրման հատակագիծ։

## Վերահավաքում Windows-ում

Սկսեք `Project` թղթապանակից։ Չափերը փոփոխելու բնօրինակներն են [սենյակներն ու պատերը](../02-design/design.json), [համակարգերը](../04-services/services.json) և [մոդելի երկրաչափությունը](scene.py)։ Պահանջվում են Python, NumPy, ReportLab, Arial և .NET Framework-ի C# կազմարկիչը։

```powershell
python 05-model/build.py
python tools/build_viewer.py
csc /optimize+ /r:System.Drawing.dll /out:..\tmp\model\Render.exe 05-model\Render.cs
..\tmp\model\Render.exe ..\tmp\model 07-views 1152 6
python tools/views.py
```

Ռենդերիչի վերջին երկու թվերը պատկերի լայնությունն են պիքսելներով և յուրաքանչյուր պիքսելի համար օգտագործվող նմուշների քանակը։ Autodesk-ի միջավայր տեղափոխելու ընթացքերը ներկայացված են [ծրագրային համեմատության մեջ](../08-review/Ծրագրային%20ընթացքեր.md)։

Անկախ վերաստուգում՝ IfcOpenShell-ով համալրված Python միջավայրում գործարկեք `python tools/verify_ifc.py`։ Ստուգվում են տարածքների մակերեսները, խողովակների ու օդատարների չափերը, բոլոր սարքերի նույնացուցիչները և եռաչափ մարմինների բացվելը։
