# CAD գծագրերի բացման հերթականություն

Պատճենեք այս պանակն ամբողջությամբ նույն տեղում։ Բացեք `01-Architecture.dwg`, ապա ցանկալի ինժեներական ֆայլը։ Յուրաքանչյուր գծագրային միավորը մեկ մետր է։ Համակարգման հենակետը (0, 0, 0)-ն է։ CAD-ում 5.92 մ կրող պատի համար հեռավորության գործիքը պետք է ցույց տա 5.92։

| Ֆայլի հիմք | Նշանակություն | Արտաքին հղում |
|---|---|---|
| X-BASE | Անշարժ պատի եզր և սյան ուրվագիծ | Ինքնուրույն հիմք |
| 00-Existing | Սկզբնական հատակագիծ | X-BASE.dwg |
| 01-Architecture | Մուտք №3, բացվածքներ, կահավորում և ուղիներ | X-BASE.dwg |
| 02-Water, 03-Drainage | Ջուր, ջրահեռացում և կանգնակի ուղղություն | 01-Architecture.dwg |
| 04-Power, 05-Lighting, 06-HVAC | Սնուցում, լուսավորություն, ջեռուցում և օդափոխություն | 01-Architecture.dwg |

Յուրաքանչյուր անունով կան DXF և DWG ֆայլեր։ Բնօրինակ DXF-ը ստեղծվում է `tools/export_cad.py`-ով։ DWG 2018-ը ստացվել է ODA File Converter 27.9-ով։ Ութ DWG-ն նորից կարդացվել և վերաարտահանվել է DXF․ ստուգվել են AC1032 ստորագրությունը, մետրային INSUNITS=6 միավորը, երկրաչափական տարրերը և հարաբերական XREF անունները։ Ճարտարապետական ֆայլի արտաքին հղումից են գալիս հիմքային տարրերը։ Եթե դրանք չեն երևում, վերաբացեք XREF-ը նույն անունով այս պանակից։ 04-services պանակի առանձին աշխատանքային DXF-ների միավորը միլիմետր է։
